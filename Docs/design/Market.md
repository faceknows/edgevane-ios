## 1. Store

| Store | 职责 |
| --- | --- |
| `SymbolSummaryStore` | `GET /stocks/summaries`，按 symbol 缓存 |
| `BarStore` | 分钟（分会话）与日线仓库；key 含 market/symbol/date/session/timeframe。扫描器、详情、交易 Tab、持仓列表 **共用同一份** 1 分钟棒。记下每次成功拉取的美东时刻（**空结果也算一次成功**）；同一美东分钟、同一 key 不重复请求。已有棒则带 `startTime`（最后一根 HH:mm）只拉增量并按时刻合并。后端不补无成交分钟，首根晚于开盘仍走增量，不要因此整段重拉 |
| `SecondBarStore` | 已订阅 symbol 的秒线环缓（约 10 分钟） |
| `QuoteStore` | 已订阅最新成交价和盘口 bid/ask：`trade` + **`quote` 为主**，`latest-snapshot`（`bp` / `ap`）兜底 |
| `SubscriptionStore` | 网关 `{ me, all }`；添加/退订 |
| `ScreenerStore` | 当前扫描器结果（一种列表，换 fetch）。每种扫描器各自记住上次筛选；离开后再进入仍用上次条件（有隐藏日期的仍刷新日期） |

详情页不自己持有网络客户端，只选 symbol、周期、开关，向这些 Store 要 `ChartModel` 零件。

## 2. 扫描器

目录屏列出第一期 8 项（需求 01），导航标题「市场数据」，列表不另标「扫描器」。

结果屏 **一个** `ScreenerResultsView`：标题、筛选（有参数的扫描器注入）、每行标题同一行均分展示代码 / 价格 / 成交量 / 涨跌幅 + 当日盘中 1 分钟迷你蜡烛（叠加蓝色 VWAP、时间轴、价格轴、最高/最低/当前价）、点进详情。ATR 最强为五列：代码 / ATR 百分比（两位小数、加粗、字号与价格相同） / 价格 / 成交量 / 涨跌幅，不显示列标题。结果行要密：少留图与图之间的空白，方便一屏多看几只。分钟棒与交易 Tab、详情共用 `BarStore`、`SubscriptionWatchSession`、`SparklineView`；列表里重复的代码只拉一次。**扫描结果默认未订阅，不画秒图、不嵌 `ChartSurface`。** VWAP 用 1 分钟棒在 `Indicators` 算完再对齐到各根蜡烛；不要再画收盘折线。分钟棒**成功返回空数组**时展示空态文案（`SparklinePane` 可配置），不要留整块空白可点图区；尚未拉完或失败走加载/重试。交易 Tab 不传空态文案，空数据仍留空。

筛选选项走共用可点芯片（`TappableValue`），不要每个扫描器各做一套 Picker。标题在左、选项同一行（挤不下则横向滚动）；单独成列时过宽再换行（iOS 15 横向滚动）。点击高度至少 44pt。价格斜率：窗口独占一行；最低价与最低量并排、各自选项同一行。方向、周期（1M/3M/5M）、窗口分钟（15/30/60/90/120）、最低量（1M/2M/5M/10M）、最低价是共用字段；点一下即改条件。动量最强：方向、周期、最低量，**不要日期**。ATR 最强：周期、窗口、最低价、最低量，**不要日期和时间**（`time` 默认空、不传，与 RN 空时间一致；窗口选项 5/10/20/30，请求仍传 `barCount`，不是价格斜率的 `spanMinutes`）。价格斜率：方向、窗口分钟、最低价、最低量，**不要日期和结束时间**（`date` 用美东日历日，与 RN `getLocalDateOfNow` 一致；`endTime` 默认空，请求时解析成当前时刻，超过 16:00 则为 16:00）。阶梯形态：方向、周期、窗口、最低价、最低量，**不要日期**（窗口选项含 0，缺省 0；最低价用 4/6/8/10；请求仍传 `barCount`）。RSI ADX：RSI、ADX、DI 差值、方向、周期，**不要日期**（开口区间不传对应 `rsiLow`/`rsiHigh`/`adxLow`/`adxHigh`；缺省 RSI 50-60、ADX 20-30、DI 20、方向上、1 分钟）。成交量增幅：最低量，**不要日期、最低价和结果数量**（请求只传 `market` / `minVolume` / `returnCount`，`returnCount` 固定前 50；缺省最低量 5M）。二级筛选器：日期、类型、最低价（5/10/20）、最低市值（500M/1B/2B）；日期用美东日历日且用户可改。每种扫描器各自记住上次条件，离开后再进入不恢复缺省。无日期控件的扫描器每次加载前刷新隐藏的日期（动量 / ATR / 阶梯为最近交易日，价格斜率为日历日），其它筛选保留。动量 / ATR / 价格斜率缺省最低量 1M；阶梯与成交量增幅缺省 5M。其它扫描器按 RN 现有 query，缺省即可。

从通知带来的 `symbols`：目录顶上 chips，点进详情。

## 3. 实时订阅（交易 Tab）

- 列表 = `SubscriptionStore.me`。每一行是一张**监视卡片**，不是扫描器那一行摘要：代码 / 价格 / 成交量 / 涨跌幅均分同一行（涨跌幅在最后），**不要盘口 bid/ask**；下方并排两张迷你折线（左：当日盘中分钟；右：秒线环缓）。
- 迷你图只画收盘折线，**不画成交量、昨收/今开价格线、买卖点、蜡烛、面积填充**。分钟图要叠蓝色 VWAP。要有时间轴、右侧价格轴、最高/最低数字（不画高低价线）、当前价（只从最后一根收到右轴的虚线）。不嵌 `ChartSurface`（多标的同时展示时 WKWebView 过重）。分钟棒来自 `BarStore` 当日 regular 1 分钟，**不聚合**，画收盘折线并叠蓝色 VWAP（VWAP 用同一套 1 分钟棒算出后对齐到各收盘点）；秒图来自 `SecondBarStore`，只取相对现在约 10 分钟内、且不晚于现在的 1 秒棒（不聚合成 5 秒）。两张迷你图都不显示周期标题。未来时间戳不进环缓。无新行情时按下一次出窗时间裁剪，新棒插入要唤醒调度，不准每秒刷新整表，也不准把过期点留在屏上。空数据留空，不准画假平线。分钟棒拉取失败时该行展示失败原因和重试（有上次折线时也要提示，不能把旧图当成最新）；休市后轮询仍会再试失败的代码，用户也可点重试。点卡片进详情是按钮；点重试只重试，不进详情。
- `SubscriptionWatchSession` 进入本页后为 `me` 里每个**去重后的**代码拉/轮询当日分钟棒（与详情、扫描器共用 `BarStore`，有界并发；同一分钟内 `BarStore` 直接复用缓存）。摘要预取与分钟监视并行，分钟图不等摘要回来。离开本页取消未完成请求（含用户点的重试；含 `BarStore` 底层 HTTP；最后一名等待者离开则不写入共享缓存），不把结果写回本页。秒线仍只靠已订阅的 Socket，本页不另拉。无秒棒时过期调度长时间休眠，新棒插入再唤醒，不准每秒空转。用户点重试才强制刷新该代码；同一代码已在排队或拉取中时再点重试不另发请求。
- 添加：输入代码 → subscribe。失败展示网关原因（含可能的服务端上限）。**客户端不按 Pro 限额拦截。**
- 退订：清该 symbol 秒线缓冲与盘口。
- 点卡片 → 详情。
- 未配券商账户：列表仍可用。
- 行情 Socket 未连接或断开：列表顶或空态旁显示「行情未连接」，不要假装没数据。

## 4. 股票详情

路由参数只要 `symbol`。

**始终：** 导航栏代码 + 涨跌幅 + 成交量缩写；右上角 **账户今日盈亏**（Trading 组合盈亏，文案不要写成该标的盈亏；纯数字，不要底、不要边框）；最新价（有订阅用 Quote 的 last；未订阅用摘要/快照）；RSI/ADX/ATR 等数字徽标（按当前 1/3/5 分钟棒现场算）、分钟图、盘前盘后、偏好控制的日线 / **纳指矮图**、加入订阅按钮。交易相关时间按美东。

**仅 `me` 含此 symbol：** 秒图（有秒线才出）、滑条（跟秒图一起，没有秒图不出）、交易条、**退订**、盘口 bid/ask 与数量（`quote` 为主，快照兜底；都没有才用成交价，Q 条显示 —）。未订阅没有交易条；标题价用摘要/快照 last。

VWAP 开关默认开（实现时若与 RN 默认不一致，跟 RN）。

3M/5M 不另存仓库，用 1 分钟聚合。

搜索：仪表盘搜索框，合法代码直接进详情（可先 summaries 校验，失败提示无此代码）。

## 5. 历史分钟 / 复盘

独立屏（仪表盘「历史分钟」入口）：选美东日期 + 已有 symbol（或本页再搜）。

- `BarsAPI` 拉该日 1 分钟（不写入「今天」的 `BarStore` 桶）。
- 本地算 VWAP；可切蜡烛/线、1/3/5 分钟。
- 若有当前券商账户：向 Trading 要该日该 symbol 的成交，编成 `ChartMarker` 叠在图上（见 [Charting.md](Charting.md) 4.1）。**模拟只标模拟、实盘只标实盘。**
- 下方可列当天成交（时间、方向、价、量），点一行等同 `pickedMarker`。
- 无账户或无成交：只看图，不报错。

这就是复盘的第一入口，不另做一套图表。

## 6. Socket 接入

登录后 `App` 打开 Platform Socket。

- `trade` / `quote` / `second-trade`：仅当 symbol ∈ `me` 才写入 Quote / SecondBar。
- 已订阅标的同时用 `latest-snapshot` 给 QuoteStore 兜底（`bp` / `ap` / `bs` / `as`；Socket `quote` 未到时盘口条也能显示数量）。
- 订阅变更后：新 symbol 开始收；退订立即停写并丢缓冲与盘口。
- 连接状态对 UI 可见。

## 7. 验收现象

- 八个扫描器都能进列表并打开详情；结果行能看到当日 1 分钟蜡烛与蓝色 VWAP，没有秒图。迷你图有时间轴、价格轴、最高/最低/当前价。无当日分钟棒时图区空态，不要留大块可点空白。
- 未订阅无秒图、无交易条；订阅后出现，并能退订。
- 切 1/3/5 分钟与蜡烛/线、VWAP 符合图表设计。切周期时分钟主图与纳指对照保持同一可见时间起止。纳指对照不响应平移、缩放和双击复位。无 VXX。
- 历史分钟 / 复盘不改变详情里「今天」的棒；有成交时图上能看到买卖点。
- 交易 Tab 能加/删订阅且不出现升级页；断线时能看出未连接。
- 已订阅列表能同时看到多只代码的当日 1 分钟收盘折线（叠蓝色 VWAP）与 1 秒折线；无成交量柱；迷你折线有时间轴、价格轴、最高/最低、当前价。点卡片进详情。分钟刷新失败时即使还有旧折线也要显示失败和重试；点重试不进详情。
