# 资讯（情绪、日历、新闻）

**状态：** 待验收  
**落点：** `Insights/`、`UI/Screens/Insights/`

## 1. 市场情绪 / 经济日历

`InsightsStore` 两个独立请求：`AIAPI` + 偏好语言。

- 进入页面拉取；失败可重试。
- 页顶固定 AI 免责声明（`L10n`，中英都有）。
- 不做个股 AI 页（Admin / 后做）。
- 不在客户端调 OpenAI/Gemini。

## 2. 新闻

- Socket `news`（Alpaca 与 IBKR 来源）写入 `NewsStore`，按 id 去重。
- 磁盘缓存最近若干条，冷启动先出缓存再等推送。**登出清空新闻缓存。**
- 列表 → 详情（标题、时间、正文/链接，字段以现网 DTO 为准）。
- 空态：暂无新闻。
- 前台可 toast（浮层，不挤动页面；自动消失；可划走）；点击进详情。

## 3. 验收

- 情绪、日历在中英切换后重新请求对应 `language`。
- 有免责声明。
- 新闻可在无推送时显示缓存（若曾经收到过）。
