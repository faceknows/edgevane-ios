# 账号、通知与设置

**状态：** 待验收

**已确认：** 不做付费用户、不做 IAP、不做套餐墙、**不做 Google / Apple 等第三方登录**。能进 App 的只有受邀请后用邮箱注册的账号。

## 1. 账号

准入模型：

```text
没有邀请码 → 不能注册
没有账号   → 不能登录
有账号     → 邮箱 + 密码登录（不检查是否付费）
```

### 注册

- 邮箱、密码 + **确认密码**、**邀请码**（必填，运营线下发放）、昵称（可选）
- **不要**邮箱验证码（跟现网注册接口一致）
- 密码至少 8 位；两次密码须一致，不一致当场拦住
- 邀请码是唯一门槛。无效、过期、缺失都必须能看懂原因
- 邮箱已占用必须能看懂原因
- 成功后进入已登录

### 登录

- 仅已注册账号：邮箱 + 密码。**只此一种登录方式**
- 失败原因可见（账号或密码错误、未授权等）
- **不出现**「用 Google 登录」「用 Apple 登录」「升级 Pro」「恢复购买」

### 找回密码（行业惯例）

- 向邮箱发验证码 → 输入新密码 + **确认新密码**（两次必须一致，不一致当场拦住）
- 成功后 **回到登录页**，用新密码再登一次（**不自动进入 App**）；旧密码失效
- 验证码可重发；失败原因可见

### 会话

- Access token + refresh token 存在本机安全存储（iOS 应用 Keychain，对应 RN 的 MMKV）
- 过期前刷新（RN 提前 5 分钟）
- 登出：清会话、清 Alpaca 凭证缓存、注销 FCM、清通知缓存、**清新闻缓存**

### 删号

- 「其他设置」里软删，成功后等同登出
- 不可恢复的说明要写清楚

**不做：** Google / Apple / 其它第三方登录、改密码独立页、手机号、任何付费套餐 / IAP。登录页只有邮箱与密码。

## 2. 实时行情订阅（不是付费）

用户把自己关心的标的加入网关，才能收秒级行情、看秒图、用交易条。

- 已登录的受邀请用户可以添加 / 退订
- **不按免费 / Pro 限数量**，不提示升级
- 不调用 `/v1/subscription/*` 付费接口
- 设置里没有「订阅套餐」页

若网关或角色配置另有技术上限（例如保护服务端），按错误提示即可，不要做成付费墙。

## 3. 推送通知

- 设置里总开关；关闭则不再注册或不再展示（与 RN `push_notifications_enabled` 对齐）
- 登录后注册 FCM token：`POST /v1/users/fcm-token`，平台 `ios`
- 登出：`DELETE /v1/users/fcm-token`
- 前台可 toast；点击按类型跳转
- 通知中心：分页历史；筛选

| 类型（产品名） | 中文 |
| --- | --- |
| Trend Up | 趋势向上 |
| Trend Down | 趋势向下 |
| Intraday High | 日内高点 |
| Intraday Low | 日内低点 |
| Breakout | 突破 |
| Weak Pullback | 弱势回调 |

深度跳转规则见 [03-用户流程与页面.md](03-用户流程与页面.md)。

偏好 `notificationVolumeThreshold`：0、2–8。0 = 不过滤。实现时与 RN 对齐过滤发生在服务端还是客户端；**通知列表与前台 toast 都要遵守同一套过滤**。

## 4. 用户偏好

与后端 `GET/PATCH /v1/users/preferences` 同步。默认值：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `valuePerTrade` | 100 | 每笔交易金额（美元） |
| `allowTradeInMinutesAfterOpen` | 30 | 开盘后多少分钟内禁止下单 |
| `showOTOAction` | false | 显示 OTO |
| `showMarketTrade` | false | **仅控制是否显示「市价全平」**。限价买/卖始终有；不因此增加市价开仓 |
| `autoTakeProfitPercent` | 0 | 自动止盈 %，0 为关 |
| `autoStopLossPercent` | 0 | 自动止损 %，0 为关 |
| `showDailyBarInDetail` | false | 详情默认显示日线 |
| `showIndexBarInDetail` | true | 详情默认显示 **纳指对照矮图**（无 VXX） |
| `getAllSubscriptions` | false | Admin：拉全部订阅 |
| `notificationVolumeThreshold` | 0 | 通知成交量阈值 |
| `locale` | null | `en` / `zh`；空则跟随系统 |

自动止盈止损有效值 0.1–1。语言切换立即作用于 UI 与 AI 接口的 `language` 参数。

自动止盈 / 止损黑名单按标的存在本机（详情交易区与偏好都能改），第一期不需要新后端字段。
