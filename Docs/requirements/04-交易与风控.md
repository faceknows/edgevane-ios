# 交易与风控

**状态：** 待验收

交易发生在 **当前券商账户** 上。第一期该账户就是用户本机配置的那一个 Alpaca（模拟或实盘）。App 不撮合、不托管资金。凭证存在本机（RN 现状），服务端不代下单。

将来一个应用账号可能绑定 Alpaca、Schwab、IBKR 等多个券商账户，见 [10-多券商账户.md](10-多券商账户.md)。**本期不实现多账户。** 设计和领域模型按「当前券商账户」来写，不要把 Alpaca Key 当成用户本人的固定属性。

## 1. 前置条件

用户要下单，必须同时满足：

1. 已登录 Moneyknows
2. 本机已保存有效的 Alpaca Key / Secret
3. 已选择模拟盘或实盘（对应 Alpaca paper / live 主机）
4. 不在「开盘保护」窗口内（见第 4 节）
5. 账户未被 Alpaca 标记为禁止交易（若接口返回 `trading_blocked`，应提示，不可静默失败）

未订阅该标的实时行情时：可以看分钟图，但秒图、滑条下单与交易条都不出现（仅已订阅才出）。底部可加入订阅。

## 2. 下单方式

数量按 **股数**，不用 Alpaca `notional`。

默认股数：

```text
股数 = max(floor(每笔交易金额 / 当前价), 1)
```

`每笔交易金额` 来自用户偏好，默认 **100 美元**。界面提供 1/3、1/2、1、2、3 倍。

价格来源（与 RN 对齐）：

| 动作 | 参考价 |
| --- | --- |
| 买 | **买一（bid）**，没有才退回最新成交 |
| 卖 | **卖一（ask）**，没有才退回最新成交 |
| 止盈 / 止损 | 中间价（(bid+ask)/2），没有盘口则最新成交 |
| 滑条下单 | 用户在秒图上选定的价格 |

盘口第一期就要：已订阅以行情 `quote`（`bp` / `ap`）为主，**同一标的用 `latest-snapshot` 兜底**；没有盘口才退回最新成交。未订阅没有交易条，标题价用摘要/快照的 last。

### 2.1 限价买 / 限价卖

- 类型 `limit`，`time_in_force = day`
- 可选盘前盘后（`extended_hours`）。**处于盘前或盘后时段时默认勾选**
- 用户可改限价与数量后再确认

### 2.2 OTO

- 偏好 `showOTOAction`，默认 **关**
- 入场限价 + 止盈限价（止盈距入场至少 0.01 美元）
- `order_class = oto`

### 2.3 止盈

- 对已有仓位挂限价离场
- 方向与仓位相反

### 2.4 止损

- 类型 `stop`
- 数量可选：可用数量 / 全部 / 自定义

### 2.5 平仓

- 市价全平：对应该标的 `closePosition`，可同时撤未完成单
- 限价平：限价离场

### 2.6 秒图滑条下单

- 仅已订阅标的
- 在秒图价格区间拖动，松手后弹出确认，挂限价
- 拖动锁定区间约 10 秒（RN：`SLIDER_OVERRIDE_DURATION_MS`），避免行情跳动把滑条拽飞

## 3. 订单与持仓展示

### 订单

用户能：

- 看全部 / 已成交 / 新建
- 按 symbol 过滤
- 取消未完成单
- 改单：未完成限价/止损单可改 **价格和/或数量**，确认框写明模拟/实盘后提交 replace

订单状态与成交均价、数量来自 Alpaca。刷新来源：

- 定时轮询账户/订单/持仓
- 网关 `trade_updates`
- 直连 Alpaca 交易 Socket（`trade_updates`）

RN 现状是 **两条通道都在**，可能重复刷新或重复提示。第一期产品要求：**用户看到的订单状态最终正确**；是否合并通道属于实现/后端提案，不改变「能取消、能看到成交」。

### 持仓

列表展示各标的数量、成本、市值、浮动盈亏。点进单标的 **只平仓、不加仓**。平仓受开盘保护。市价全平仍跟 `showMarketTrade`；限价平始终可走。加仓走该标的详情交易条（须已订阅）。

### 投资组合

展示：净值、上一交易日净值推导的今日盈亏与百分比、购买力、现金。  
刷新：开盘 **3 秒**、收盘 **15 秒**（不必 1 秒，但开盘要明显更勤）。

今日盈亏跌幅达到 **-1.5%** 时，仪表盘用警示色（RN：`DAILY_PNL_WARNING_THRESHOLD`）。

## 4. 时段与保护

均按 **美国东部时间**。

| 时段 | 时间 | 产品含义 |
| --- | --- | --- |
| 盘前 | 04:00–09:30 | 可勾选盘前盘后交易；默认可开 |
| 常规 | 09:30–16:00 | 正常交易 |
| 盘后 | 16:00–20:00 | 同盘前 |
| 开盘保护 | 09:30 起 N 分钟 | **禁止下单**，提示等待。N 来自偏好，默认 **30** |
| 休市 / 假期 | `dateHelper` + 美国市场假期表 | 按休市展示，不假装开盘 |

角色配置若下发单笔上限（如 `MAX_ORDER_VALUE`），下单不得超过该值。

## 5. 自动止盈 / 自动止损

用户在偏好里设百分比，范围 **0.1–1**，单位是「百分之 x」（0.2 表示 0.2%）。**0 或未设 = 关闭**。默认关闭。

当一笔 **入场成交**（且不是自动单自己）发生时：

1. 刷新该标的仓位
2. 按成本价 ± 百分比计算离场价，价差至少 0.01 美元
3. 撤掉该标的已有自动单（client id 前缀 `auto-tp-` / `auto-sl-`）
4. 再挂新的限价止盈或止损单（保护窗内不挂）
5. 成功或失败要有提示；失败可有限次重试（RN 最多 2 次）

用户可把某标的加入/移出自动止盈或自动止损黑名单（详情交易区与偏好里都能改），之后该标的不再自动挂。

自动止盈和止损都挂在统一订单流上：只连上网关也能两条都生效，不依赖必须同时连上 Alpaca 直连 Socket。

开盘保护窗内 **不挂** 自动单（与手动下单同一套拦截），失败要提示。

## 6. 模拟盘与实盘

设置页明确区分。切换后必须：

- 换主机
- 清空并重拉该环境的订单、持仓、组合
- 界面持续可见当前是模拟还是实盘，避免下错环境

## 7. 失败时用户应看到什么

- 凭证无效 / 401：引导去凭证页
- 数量为 0、价格非法、保护窗：本地拦截并说明
- Alpaca 拒单：展示返回原因，不要只 toast「失败」
- 自动单失败：说明哪个标的、止盈还是止损
