# 范围与分期

**状态：** 待验收

把 RN 里「已经存在」和「iOS 第一期要做」分开，避免把半残功能或 Admin 工具默认搬过来。

## 1. 建议的第一期（普通用户主路径）

与当前 RN **受邀请后可见** 的主路径对齐，但 **去掉付费**：

1. 版本检查门禁 → 登录 / **邀请码注册** / 找回密码（生产包覆盖现网 `com.byteknows.moneyknows`）
2. 底栏：首页、交易、设置
3. 仪表盘：今日盈亏、持仓摘要、订单摘要、搜索、快捷入口
4. 股票详情：分钟 K 线（1/3/5 分钟）、蜡烛/线图、VWAP、昨收/今开等价格线、缩放平移；可选日线、可选纳指对照矮图（**不要 VXX**）
5. 已订阅标的：秒级图 + 交易操作（限价买卖、平仓、止盈止损；OTO 与市价由偏好控制）；可退订。盘口消费 `quote`，快照兜底
6. 交易 Tab：我的实时订阅列表（**不按套餐限量、不提示升级**）
7. 扫描器入口（当前菜单可见的 8 项，见第 3 节）
8. 市场情绪、市场事件、新闻、通知、历史分钟 / 复盘（选日 + 当天买卖点）
9. 持仓列表 / 持仓详情平仓 / 投资组合 / 订单列表（取消、改单）
10. 设置：Alpaca 凭证（模拟/实盘）、用户偏好、资料、推送开关、深色模式、删号、登出
11. 推送：授权、历史列表、点击跳转详情或扫描器

## 2. 建议第一期不做（除非你改口）

| 项 | 原因 |
| --- | --- |
| Android | 继续用 RN |
| Google / Apple / 其它第三方登录 | **已确认不做。** 只做邮箱注册、登录、找回密码 |
| 客户端直连 OpenAI / Gemini 做交易计划 | 密钥在端上，不适合作为 iOS 主路径 |
| 自研毫秒级图 / SciChart | 已确认不需要 |
| 完整 TradingView 画线、指标脚本 | 超出「基本看图」 |
| IBKR 账户交易 | RN 也没有 |
| 独立 Onboarding 引导页 | RN 没有 |
| 付费套餐 / IAP / 升级墙 | **已确认不做。** 现网无真正付费用户。准入只保留邀请码注册 + 已有账号登录 |
| VXX 对照图 | **已确认不做** |
| 多券商账户（Alpaca + Schwab + IBKR…） | **已确认：只作设计预留，第一期不实现。** 见 [10-多券商账户.md](10-多券商账户.md) |
| 订阅购买页、订阅问题（IAP 客服） | 随付费一起拿掉 |

## 4. Admin / 调试能力

RN 里仅管理员能看到。建议 **第一期可后做**，不挡普通用户闭环：

- 邀请用户（邀请码由运营线下发，App 内不做）
- 本地存储调试页
- 个股 AI View（`SymbolsAiView`）
- 个股价格通知编辑（`SymbolNotification`）
- 偏好里的「获取全部订阅」
- 组件展示 / EnvTest / ApiTest（测试页，产品不需要）

## 5. 半残或入口断开，默认不进第一期

| 项 | RN 现状 |
| --- | --- |
| 微观分析页 | 路由在，详情页入口已注释；Socket 实时特征处理也被注释，主要靠 REST 回填 |
| 分钟 K 线直播成棒 | Store 有 `appendBar`，没有任何调用；分钟线靠每分钟 REST 拉取 |
| IBKR Socket 报价进列表 | 事件有，几乎没接到界面 |
| 类型里的 `ManageTradeSymbols` | 没有对应屏幕 |

若你希望 iOS **顺带修**「分钟线用推送增量更新」而不是继续 60 秒拉全量，这是后端/协议优化，见 [06-后端接口与复用.md](06-后端接口与复用.md) 提案，**不是默认范围**。

## 6. 分期原则

- 第一期 = 受邀请用户主路径 + 已确认图表能力。**不含付费。**
- 隐藏扫描器、Admin、微观分析、客户端 AI = 第二期或单独拍板。
- 后端提案默认全部不采纳，除非你在第 08 篇勾选。
- 后端若仍返回 `subscription` 字段或 IAP 接口，iOS **不展示、不购买、不按套餐限权**。
