# 用户流程与页面

**状态：** 已验收

描述用户能走到哪里、每页做什么。路由名沿用 RN，方便对照，实现时可以改名。

## 1. 启动

```text
启动
  → 版本检查中 / 失败可重试 / 过低则强制跳转商店
  → 通过后
       未登录 → 登录（可去 **邀请码注册**、找回密码）
       已登录 → 主界面（底栏）
```

没有独立引导页，也没有付费墙。注册必须填有效邀请码（不要邮箱验证码），成功后直接进入已登录。已有账号只用邮箱密码登录。

推送冷启动：按通知类型进入通知列表、股票详情，或扫描器并带上相关 symbol。

## 2. 信息架构

底栏三栏：

| Tab | 中文 | 默认页 |

## 3. 首页栈

| 页面 | 用户能做什么 |
| --- | --- |
| 仪表盘 | 看今日盈亏（卡片上标明模拟/实盘）、持仓数/摘要、订单摘要；搜代码；进扫描器/情绪/事件/通知/新闻/历史分钟 |
| 通知 | 按类型、代码筛选；分页；点进详情或扫描器 |
| 持仓 | 列表刷新；点卡片进标的详情；可按买价买 / 按卖价卖 |
| 投资组合 | 净值、购买力、现金、今日/总盈亏（定时刷新） |
| 交易记录 | 全部 / 已成交 / 新建；点当日成交代码筛选；短输入框回车查非当日订单；滚到底加载更早订单；取消；有可撤销单时全部撤销 |
| 市场数据 | 扫描器目录；若从通知来则展示相关代码 chips |
| 各扫描结果页 | 有参数的扫描器可点选项改条件（动量：方向、周期、最低量；ATR：周期、窗口、最低价、最低量；价格斜率：方向、窗口、最低价、最低量；阶梯：方向、周期、窗口、最低价、最低量；RSI ADX：RSI、ADX、DI、方向、周期；成交量增幅：最低量；二级筛选器：日期、类型、最低价、最低市值；除二级筛选器外都不要日期）；同一行均分代码、价格、成交量、涨跌幅（ATR 最强为五列：代码、ATR 百分比、价格、成交量、涨跌幅）+ 当日 1 分钟蜡烛（含蓝色 VWAP、时间轴、价格轴、最高/最低/当前价）；行距要紧，一屏多看几只；未订阅无秒图；无当日分钟棒时图区空态；点代码进详情 |
| 市场情绪 | 读 AI 盘中情绪（服务端） |
| 市场事件 | 今日美股高影响事件 |
| 新闻 / 新闻详情 | 列表来自已收到的新闻流 |
| 历史分钟 / 复盘 | 指定日期拉 K 线 + VWAP；有券商账户则在图上标当天买卖点；不污染当日缓存 |

## 4. 交易 Tab

| 页面 | 用户能做什么 |
| --- | --- |
| 实时订阅 | 同时看已订阅多只代码的当日分钟折线与秒级折线（无成交量；有时间轴、最高/最低；不画右侧价格轴）；添加 / 退订（**不按套餐限量**）；点进详情 |

未配置 Alpaca 凭证时：仍可看行情与扫描；交易操作不可用，应能引导去设置里填凭证。

## 5. 股票详情（核心页）

用户能：

1. 看代码、涨跌、**账户今日盈亏徽标**（组合账户盈亏，不是该标的）、RSI/ADX/ATR。交易相关时间按 **美东** 展示。
2. 切 1 / 3 / 5 分钟；切蜡烛 / 折线；开关 VWAP。
3. 看盘前、盘中、盘后分钟图（盘前盘后按 RN：5 分钟聚合展示）。
4. 按偏好显示日线、纳指对照矮图（不要 VXX）。
5. 缩放、平移 K 线；看到昨收、今开等价格线。
6. 未订阅：盘中分钟图下显示摘要最新价；底部可加入实时订阅。
7. 已订阅：可退订；秒级图（缺省 1 秒折线，可切 1/5/10/30 秒和蜡烛/线）+ 价格滑条快捷下单 + 完整交易条。成交价与盘口在盘中分钟图下方、买卖按钮上方。今日已成交可标在分钟主图上。
8. Admin（若第一期不做，则本页不出现）：AI View、价格通知。

## 8. 前台 Toast

订单创建/取消/成交、新闻、推送提醒用浮层 toast（与 RN `Toast` 同类），**盖在当前页上，不插入布局、不挤动页面**。数秒后自动消失。用户看到后也可把这条提醒划出窗口关掉。新闻、通知、凭证类 toast 点按仍按上表跳转；点按或划走后这条提醒消失。

## 9. 空态与错误（产品要求）

用户必须能看懂，而不是转圈消失：

- 未登录不能进主界面
- 版本过低只能更新或退出
- 网络失败可重试
- 无持仓 / 无订单 / 无通知 / 无新闻有空态文案
- 扫描器结果行没有当日分钟棒：图区空态，不要留大块空白
- Alpaca 未配置或密钥错误：交易相关区块说明原因
- 开盘保护时段下单：说明还要等几分钟（按美东）
- 行情 Socket 断开：交易 Tab / 详情能看出「行情未连接」，可理解不是没数据而是断线
- AI 页展示免责声明（RN 已有中英文案）
