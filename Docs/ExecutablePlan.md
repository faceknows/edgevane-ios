# money-ios 可执行方案

本文规定 **怎么做**，不代替需求正文，也不代替设计正文。

**当前门：阶段 C，按切片实现。** 需求与功能设计已验收。对照 `Docs/design/` 写代码，不要另起接口。

## 1. 目标

把现有 React Native App（Moneyknows / `money-app`）用原生 iOS 重构一遍，做成可长期演进的美股盘中交易辅助客户端。

- 产品行为以已验收的 `Docs/requirements/` 为准。
- 后端默认复用现有 `money-api` 与 `money-gateway`。
- 需要增删或优化接口时，先写进需求「后端提案」，确认后再进设计。

## 2. 工作方式

三个大阶段，顺序固定：

```text
A. 需求（写清产品是什么、不是什么、与 RN 的对等关系）
        ↓ 验收
B. 设计（模块边界、图表、网络、第一个可运行客户端怎么落地）
        ↓ 验收
C. 实现（一次只做一个可交付切片）
        ↓ 每步单独验收
```

规则：

1. **先文档，后代码。** 产品行为以 `Docs/requirements/` 为准；结构以 `Docs/design/` 为准。
2. **渐进。** 每一步交付可在真机或模拟器上操作的结果，而不是半截屏幕。
3. **清晰。** 每一步写明范围、不做、验收。验收用现象，不用“代码写完了”。
4. **不把 RN 现状当天花板。** `money-app` 证明过哪些能力存在；隐藏入口、Admin 专属、半残功能要在需求里单独标出，由产品决定带不带进 iOS。
5. **不在实现步偷偷发明后端。** 现有 HTTP / Socket 是近期约束。要改协议，回到需求提案。

近期约束（可在后续需求里改）：

- 第一个客户端只做 iOS。Android 仍走现有 RN，不在本期范围。
- 主图用 Lightweight Charts；仪表盘类统计图用 Swift Charts。
- 不追求毫秒级图表。

## 6. 验收怎么做

- **阶段 A：** 已收口。
- **阶段 B：** 已通过。
- **阶段 C：** 每步有可操作现象（例如：未登录看到登录页；登录后看到仪表盘今日盈亏）。

### C0 验收

- 冷启动先版本检查；过低只能去商店或退出；失败可重试。
- 登录页只有邮箱密码，没有 Google / 升级。
- 注册必须填邀请码，没有邮箱验证码；成功进入三栏。
- 忘记密码成功后停在登录页。
- 杀进程再开，令牌有效则仍在三栏；登出回到登录。

### C1 验收

- 设置首页有：凭证、偏好、资料、其它、推送开关、外观、语言、登出。没有套餐 / Google / Admin。
- 凭证：Key + Secret + 模拟/实盘；校验失败时旧账户仍在；清空两项可删该环境凭证。
- 改偏好一项即 PATCH；语言立刻换文案；「显示市价全平」不是「市价交易」。
- 资料只读：昵称、邮箱、角色、role-config；没有套餐/到期/续费。
- 删号确认后退出登录；登出清 Alpaca 凭证。

### C2 验收

- 仪表盘有搜索、今日概览（盈亏/持仓/订单，C5 前为空态）、快捷入口。扫描器可进；情绪/事件/通知/新闻/历史分钟是占位。
- 扫描器目录只有第一期 8 项；点进同一套结果列表；点行进详情。价格斜率可改日期/窗口/方向/最低价量。
- 搜索合法代码：先 summaries 校验，成功进详情；无此代码有提示。详情有代码、摘要价、指标，没有 K 线（C3）。
- 没有隐藏扫描器、套餐、Google。登出丢弃未完成的扫描结果。

### C3 验收

- 详情有当日分钟主图；能切 1/3/5 分钟和蜡烛/折线。
- VWAP 默认开，关掉后线消失；3/5 分钟柱变少，VWAP 仍按 1 分钟算。
- 快照有昨收/今开时图上有对应虚线。
- 能缩放、平移、十字光标读 OHLC、美东时间和成交量。加载中不显示空态；失败可重试。无数据时空态，没有假平线。
- 进详情可先展示缓存，盘中每分钟再拉该会话并写回缓存；重试必打网。详情一直开着跨过开盘/收盘/午夜时按新日期清棒再拉。
- 同一详情 session 换代码时立刻换成新代码的缓存（没有则空图），不把上一支的 K 线和昨收/今开线留在图上。
- 盘前/盘后有数据才出现。没有秒图、日线、纳指矮图、VXX。

### C4 验收

- 交易 Tab 列出我的实时订阅；可添加代码、退订；失败显示网关原因。没有套餐限额、没有升级页。
- 行情 Socket 未连接或断开时，交易 Tab 与详情能看出「行情未连接」，不要假装没数据。
- 未订阅详情：标题价用摘要/快照；底部可加入订阅；没有秒图、没有交易条/滑条。
- 已订阅详情：标题价用 `trade` 最新价（没有则摘要）；有 bid/ask（`quote` 为主，快照兜底，都没有才用成交价）；有秒图，能切 1/5/10/30 秒和蜡烛/折线，并跟最新；可退订，退订后秒图与盘口立刻消失。
- 登出清订阅内存、秒线缓冲、盘口，并断开行情 Socket。
- 没有日线、纳指矮图、VXX、交易条、价格滑条（C5/C6/C7）。

### C5 验收

- 无凭证：行情仍可用；仪表盘 / 组合 / 持仓 / 订单说明去设置填凭证，并能进凭证页。没有第二券商入口。
- 有凭证：仪表盘今日盈亏、持仓数量、订单数量来自当前账户；今日盈亏跌幅 ≤ **-1.5%** 用警示色。界面能看出模拟 / 实盘。
- 组合页：净值、上一交易日净值、购买力、现金、今日盈亏。
- 持仓列表可刷新；点进详情看数量、成本、市值、浮动盈亏。没有加仓（加仓走详情交易条，C6）。没有平仓按钮（C6）。
- 订单列表：全部 / 成交 / 新建；按 symbol 过滤；未完成单可取消，确认框写明模拟 / 实盘。没有改单、没有交易条 / 滑条 / 自动止盈止损（C6）。
- 切换模拟 / 实盘或保存新凭证后，组合 / 持仓 / 订单换成新环境。登出清这些内存。
- 前台刷新：常规开盘约 3 秒，否则约 15 秒。`trading_blocked` 时能看出不能交易。
