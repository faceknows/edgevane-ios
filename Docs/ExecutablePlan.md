# money-ios 可执行方案

本文规定 **怎么做**，不代替需求正文，也不代替设计正文。

**当前门：C11 扫描器筛选（动量、ATR、价格斜率、阶梯、RSI ADX、成交量增幅、二级筛选器）进行中。** C0–C10 已完成。未另开切片前，不把隐藏扫描器、Admin、微观分析当既定范围。

## 1. 目标

把现有 React Native App（Moneyknows / `money-app`）用原生 iOS 重构一遍，做成可长期演进的美股盘中交易辅助客户端。

- 产品行为以已验收的 `Docs/requirements/` 为准。
- 后端默认复用现有 `money-api` 与 `money-gateway`。
- 需要增删或优化接口时，先写进需求「后端提案」，确认后再进设计。

## 2. 工作方式

三个大阶段，顺序固定：

```text
A. 需求（写清产品是什么、不是什么、与 RN 的对等关系）
        ↓ 验收
B. 设计（模块边界、图表、网络、第一个可运行客户端怎么落地）
        ↓ 验收
C. 实现（一次只做一个可交付切片）
        ↓ 每步单独验收
```

规则：

1. **先文档，后代码。** 产品行为以 `Docs/requirements/` 为准；结构以 `Docs/design/` 为准。
2. **渐进。** 每一步交付可在真机或模拟器上操作的结果，而不是半截屏幕。
3. **清晰。** 每一步写明范围、不做、验收。验收用现象，不用“代码写完了”。
4. **不把 RN 现状当天花板。** `money-app` 证明过哪些能力存在；隐藏入口、Admin 专属、半残功能要在需求里单独标出，由产品决定带不带进 iOS。
5. **不在实现步偷偷发明后端。** 现有 HTTP / Socket 是近期约束。要改协议，回到需求提案。

近期约束（可在后续需求里改）：

- 第一个客户端只做 iOS。Android 仍走现有 RN，不在本期范围。
- 主图用 Lightweight Charts；仪表盘类统计图用 Swift Charts。
- 不追求毫秒级图表。

## 6. 验收怎么做

- **阶段 A：** 已收口。
- **阶段 B：** 已通过。
- **阶段 C：** 第一期切片 C0–C10 已完成。**当前切片 C11。** 每步有可操作现象（例如：未登录看到登录页；登录后看到仪表盘今日盈亏）。

### C0 验收

- 冷启动先版本检查；过低只能去商店或退出；失败可重试。
- 登录页只有邮箱密码，没有 Google / 升级。
- 注册必须填邀请码，没有邮箱验证码；成功进入三栏。
- 忘记密码成功后停在登录页。
- 杀进程再开，令牌有效则仍在三栏；登出回到登录。

### C1 验收

- 设置首页有：凭证、偏好、资料、其它、推送开关、外观、语言、登出。没有套餐 / Google / Admin。
- 凭证：Key + Secret + 模拟/实盘；校验失败时旧账户仍在；清空两项可删该环境凭证。
- 改偏好一项即 PATCH；语言立刻换文案；「显示市价全平」不是「市价交易」。
- 资料只读：昵称、邮箱、角色、role-config；没有套餐/到期/续费。
- 删号确认后退出登录；登出清 Alpaca 凭证。

### C2 验收

- 仪表盘有搜索、今日概览（盈亏/持仓/订单，C5 前为空态）、快捷入口。扫描器可进；情绪/事件/通知/新闻/历史分钟是占位。
- 扫描器目录只有第一期 8 项；点进同一套结果列表；点行进详情。价格斜率可改日期/窗口/方向/最低价量。
- 搜索合法代码：先 summaries 校验，成功进详情；无此代码有提示。详情有代码、摘要价、指标，没有 K 线（C3）。
- 没有隐藏扫描器、套餐、Google。登出丢弃未完成的扫描结果。

### C3 验收

- 详情有当日分钟主图；能切 1/3/5 分钟和蜡烛/折线。
- VWAP 默认开，关掉后线消失；切 3/5 分钟后柱变少，VWAP 按该周期的棒重算，不把 1 分钟 VWAP 叠上去。
- 快照有昨收/今开时图上有对应虚线。
- 能缩放、平移、十字光标读 OHLC、美东时间和成交量。左滑时最新一根钉在右缘，不要露出未来空白；放大后看历史时最新一根可以出画。加载中不显示空态；失败可重试。无数据时空态，没有假平线。
- 进详情可先展示缓存，盘中每分钟再拉该会话并写回缓存；重试必打网。详情一直开着跨过开盘/收盘/午夜时按新日期清棒再拉。
- 同一详情 session 换代码时立刻换成新代码的缓存（没有则空图），不把上一支的 K 线和昨收/今开线留在图上。
- 盘前/盘后有数据才出现。没有秒图、日线、纳指矮图、VXX。

### C4 验收

- 交易 Tab 列出我的实时订阅；可添加代码、退订；失败显示网关原因。没有套餐限额、没有升级页。
- 行情 Socket 未连接或断开时，交易 Tab 与详情能看出「行情未连接」，不要假装没数据。
- 未订阅详情：标题价用摘要/快照；底部可加入订阅；没有秒图、没有交易条/滑条。
- 已订阅详情：标题价用 `trade` 最新价（没有则摘要）；有 bid/ask（`quote` 为主，快照兜底，都没有才用成交价）；有秒图，缺省 1 秒折线，能切 1/5/10/30 秒和蜡烛/折线，并跟最新；可退订，退订后秒图与盘口立刻消失。
- 登出清订阅内存、秒线缓冲、盘口，并断开行情 Socket。
- 没有日线、纳指矮图、VXX、交易条、价格滑条（C5/C6/C7）。

### C5 验收

- 无凭证：行情仍可用；仪表盘 / 组合 / 持仓 / 订单说明去设置填凭证，并能进凭证页。没有第二券商入口。
- 有凭证：仪表盘今日盈亏、持仓数量、订单数量来自当前账户；今日盈亏跌幅 ≤ **-1.5%** 用警示色。列表页模拟 / 实盘徽标只在今日盈亏卡片。
- 组合页：净值、上一交易日净值、购买力、现金、今日盈亏。
- 持仓列表可刷新；点卡片进标的详情。加仓/平仓在 C6。
- 订单列表：全部 / 成交 / 新建；当日成交代码可点筛选；短输入框回车查非当日。滚到底加载更早订单。未完成单可取消，确认框写明模拟 / 实盘。没有改单、没有交易条 / 滑条 / 自动止盈止损（C6）。
- 切换模拟 / 实盘或保存新凭证后，组合 / 持仓 / 订单换成新环境。登出清这些内存。
- 前台刷新：常规开盘约 3 秒，否则约 15 秒。`trading_blocked` 时能看出不能交易。

### C6 验收

- 无凭证能看行情，不能下单；交易条有入口去设置填凭证。没有付费、没有第二券商入口。
- 开盘保护窗内（美东交易日 09:30 起 N 分钟，假期不算）手动下单、平仓、自动止盈止损都被拦，并说明还要等几分钟。
- 已订阅详情有交易条：限价买/卖始终可走；盘前/盘后默认勾选盘前盘后；下单弹窗写出代码、方向、价格、股数、模拟或实盘（点确认即提交）。限价单出现在订单列表。
- 已订阅秒图有价格滑条：松手后确认弹窗标明模拟或实盘，再挂该价的限价单；拖动时价格区间约 10 秒内不被行情拽飞。
- 持仓列表点卡片进标的详情，无单独持仓页。每行「按买价买 / 按卖价卖」进同一套 TradeTicket。已订阅详情交易条可加仓与平仓；限价平始终可走；市价全平仅当偏好打开。平仓受开盘保护。
- 订单列表不提供改单（底层 `replace` 保留）。未完成单可取消，确认框按钮为「保留」「撤销」，并写明模拟/实盘。取消后状态会更新（即使只有网关推送）。
- 偏好打开自动止盈/止损后，入场成交会按成本 ± 百分比挂离场单（黑名单跳过；不依赖必须同时连上 Alpaca Socket）。模拟/实盘切换后列表换成新环境。

### C7 验收

- 仪表盘「历史分钟」打开复盘页：选美东日期 + 代码，看到该日分钟图（可切 1/3/5、蜡烛/折线）和 VWAP；不改变详情里「今天」的棒。
- 有当前券商账户且该日有成交：图上买为蓝色 ∨、卖为蓝色 ∧，落在成交价与时间；点标记或下方列表能对上那一笔；模拟只标模拟、实盘只标实盘；一笔成交一个点。
- 无账户或该日无成交：只看图，不报错。
- 详情今日主图可叠今日成交（同一套标记）。
- 偏好打开时详情有纳指对照矮图（COMP），不叠进主图价格轴，无 VXX；关掉则不显示。正在看 COMP 时不再叠一层纳指。切 1/3/5 时纳指与分钟主图同一可见时间起止，切换不跳窗。纳指对照不响应平移、缩放和双击复位。

### C8 验收

- 仪表盘「情绪 / 市场事件 / 新闻」进入真实页，不是占位。通知仍占位。
- 情绪、日历页顶有 AI 免责声明；失败可重试；切换中/英后请求带对应 `language=zh|en`（跟随系统时按系统语言）。
- 情绪在窗口外可展示不可用说明。没有个股 AI 页，客户端不调 OpenAI/Gemini。
- 新闻空态为暂无新闻；曾经收到过则可在无推送时显示缓存。前台新新闻可 toast，点进详情。
- 登出后新闻缓存不可见。Alpaca 与 IBKR 新闻按 id 合并去重；IBKR 报价/成交不进行情 Store。

### C9 验收

- 仪表盘「通知」进入历史页，不是占位。类型 + 代码可筛；空态能区分「还没有任何通知」和「筛选后没有」。
- 推送总开关关掉后，App 不再向系统要权；历史仍可打开只读。打开且已登录时向现网注册 `platform: ios`；登出注销 token，历史缓存不可被下一账号看到。
- 点一条只有一个代码的通知进股票详情。趋势/日内高或低且 `screen=Markets` 打开扫描器目录并带 symbol chips。冷启动或未登录点开：版本门禁与登录通过后只跳一次；门禁未过不跳。
- `notificationVolumeThreshold`（0 = 不过滤）对历史列表和前台 toast 用同一套规则；与 RN 一样，没带成交量字段的条目不过滤掉。
- 没有 Admin 价格通知编辑，没有「升级解锁通知」。

### C10 验收

- 交易 Tab 每只已订阅代码一张卡片：代码 / 价格 / 成交量 / 涨跌幅均分同一行（涨跌幅在最后，不要 bid/ask）；下方并排当日分钟折线与秒级折线。
- 迷你图没有成交量柱、不是蜡烛。分钟折线叠蓝色 VWAP。无数据时空着，没有假平线。分钟加载失败有失败提示和重试，休市后仍会再试。有上次折线时刷新失败仍显示失败和重试，不能把旧图当成最新。
- 可添加 / 滑动退订；点卡片进详情（VoiceOver 为按钮）；点重试只重试，不进详情。离开本页取消未完成的分钟拉取（含重试），不写入共享缓存。无秒棒时不每秒空转。Socket 断开时仍能看出「行情未连接」。

### C11 范围

扫描器结果页补筛选，且方向 / 周期 / 最低价 / 最低量 / 窗口 / RSI / ADX / DI 走共用可点芯片，不各做一套。

- **动量最强：** 方向、周期、最低量。不要日期控件。点选项立刻重查。
- **ATR 最强：** 周期、窗口、最低价、最低量。不要日期和时间控件。`time` 默认空、不传（与 RN 空时间一致）。窗口请求仍传 `barCount`。
- **价格斜率：** 方向、窗口分钟、最低价、最低量。不要日期和结束时间控件。点选项立刻重查。
- **阶梯形态：** 方向、周期、窗口、最低价、最低量。不要日期控件。点选项立刻重查。缺省：方向上、1 分钟、窗口 0、最低价 6、最低量 5M。窗口请求仍传 `barCount`。
- **RSI ADX：** RSI、ADX、DI 差值、方向、周期。不要日期控件。开口区间不传对应上下限（与 RN 一致）。缺省：RSI 50-60、ADX 20-30、DI 20、方向上、1 分钟。
- **成交量增幅：** 最低量。不要日期、最低价、结果数量控件。请求只传 RN 合同字段 `market` / `minVolume` / `returnCount`，其中 `returnCount` 固定 50。缺省：最低量 5M。
- **二级筛选器：** 日期、类型、最低价、最低市值。点选项立刻重查。每种扫描器各自记住上次条件；离开后再进入（含切到其他扫描器再回来）仍用上次条件。缺省：最活跃、最低价 10、最低市值 1B。
- 无日期控件的扫描器每次进入或点筛选，在保留其它条件的同时刷新隐藏的日期/时间：动量 / ATR / 阶梯用美东最近交易日；价格斜率用美东日历日、结束时间为空并在请求时解析成当前时刻（超过 16:00 则为 16:00），与 RN 缺省一致。RSI ADX、成交量增幅接口不传日期。动量 / ATR / 价格斜率缺省最低量 1M；阶梯与成交量增幅缺省 5M。

### C11 不做

- 热门筛选器的筛选 UI（后续切片）。
- 隐藏扫描器、Admin。

### C11 验收

- 动量最强能点方向 / 周期 / 最低量，立刻看到对应列表；没有日期选择。
- ATR 最强能点周期 / 窗口 / 最低价 / 最低量，立刻看到对应列表；没有日期、时间输入。结果五列：代码、ATR 百分比、价格、成交量、涨跌幅。

- RSI ADX 能点 RSI / ADX / DI / 方向 / 周期，立刻看到对应列表；没有日期选择。
- 成交量增幅能点最低量，立刻看到对应列表；没有日期、最低价、结果数量选择；请求只取前 50。
- 二级筛选器能点日期 / 类型 / 最低价 / 最低市值，立刻看到对应列表；切到其他扫描器再回来，仍是上次选的日期和条件。
- 跨过一个交易日后再进入同一扫描器，或在页内再点筛选：动量 / ATR / 阶梯请求用新的最近交易日；价格斜率请求用新的美东日历日和当前结束时刻；其它筛选条件仍是上次选的。
